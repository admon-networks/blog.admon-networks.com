# 記事化シート

すべての欄を「値」「【要記入】」「書かない」のどれかにする。空欄のまま渡さない。
一言で終わる欄は、「なぜ」「どうなった」を足すか、「書かない」にする。

## 体験記の深掘り（体験記のみ）
- 苦手だったところ：分野 → なぜ苦手か → どう対策したか、または捨てたか
- 失敗した・落ちた理由：表面的な理由 → 本質的な理由
- 役立ったこと：何がわかるようになったか → 実務で何が変わったか（場面を1つ）
- 別の資格・仕事へのつながり：何が → なぜつながったと思うか
- 当日の様子：前の回（または予想）と比べて、気持ちや状況がどう違ったか → その理由
